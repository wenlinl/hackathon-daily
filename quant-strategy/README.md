# quant-strategy 量化策略开发骨架

一套可直接运行的 A 股日线量化策略骨架，覆盖完整闭环：

`数据下载 → 指标计算 → 信号生成 → 回测 → 绩效报告`

内置策略为**多指标趋势跟踪**（参考 BigQuant 公开示例，2026-08 调参优化后）：

1. **市场择时**：股票池中 20 日 / 60 日动量向上的股票占比分别 ≥50% / ≥25% 时才允许建仓，否则空仓；
2. **个股筛选**：EMA20 > EMA60（均线多头）、MACD 金叉发生在最近 10 天内且柱状图为正、RSI(14) 位于 35–75、收盘价高于布林带中轨；
3. **打分排序**：MACD 柱（40%）+ 20 日动量（35%）+ RSI（25%）按排名打分，取前 N 只等权持有；
4. **买入节奏**：每 5 个交易日按信号补仓新候选（不强制定时卖出）；
5. **出场与风控**：持仓不再满足选股条件（信号失效）才卖出；ATR×2.5 跟踪止损 + −10% 硬止损 + 最长持有 120 天兜底；择时信号转弱时整体清仓。

## 快速开始

```bash
# 首次安装依赖（pandas / numpy / matplotlib / requests）
python3 -m pip install -r requirements.txt

# 运行完整流程（默认股票池、2022 年至今）
python3 main.py

# 自定义参数
python3 main.py --start 2021-01-01 --end 2026-08-12 \
  --top-n 10 --rebalance 5 --stop-loss 0.10 --take-profit 0.25 --max-hold 45
```

运行后产物在 `output/` 目录：

| 文件 | 内容 |
| --- | --- |
| `nav.csv` | 每日净值、现金、持仓市值 |
| `trades.csv` | 每笔交易的买卖明细与盈亏 |
| `latest_signals.csv` | 最新交易日的候选信号与打分 |
| `report.json` | 绩效指标汇总 |
| `equity_curve.png` | 净值曲线与回撤图（对比沪深300） |
| `cache/*.csv` | 行情数据缓存（前复权） |

默认股票池为**沪深300 + 中证500 全成分（800 只，2026-08 当前成分）**，历史数据覆盖
2016-01 至今；快速演示可切回 30 只大盘股池：`python3 main.py --universe config/universe.json`。
首次运行会从网络下载数据（东财 → 腾讯 → Baostock 三源自动回退），之后全部走本地缓存
（`output/cache_all.pkl` 合并缓存，加载仅需数秒）。

## 关键参数（`main.py --help`）

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `--top-n` | 10 | 每期持有股票数量 |
| `--rebalance` | 5 | 调仓周期（交易日） |
| `--stop-loss` | 0.10 | 硬止损幅度 |
| `--trail-atr` | 2.5 | ATR 跟踪止损倍数 |

| `--breadth20` / `--breadth60` | 0.50 / 0.25 | 市场择时动量多头占比阈值 |

| `--universe` | config/universe.json | 股票池文件 |

## 回测假设（务必阅读）

- 信号在 T 日收盘后计算，T+1 日开盘价成交，**无未来函数**；
- 佣金按成交额 0.025% 双边、单笔最低 5 元；卖出另收印花税 0.05%；滑点默认 0.05%；
- 遵守 A 股 T+1 规则：当日买入的股票当日不能卖出；买入按 100 股整数倍；
- 停牌股票当日不交易，持仓按最近收盘价估值；
- 数据为前复权日线；未考虑分红再投资、涨跌停无法成交等细节；
- **回测结果不代表未来收益，仅供研究学习，不构成投资建议。**

## 扩展自己的策略

1. 改参数：直接改 `main.py` 命令行参数即可；
2. 换股票池：编辑 `config/universe.json`；
3. 换策略：在 `src/strategy.py` 里改筛选条件和打分公式；
4. 换周期：`src/data.py` 中 `klt=101` 改为分钟线，并相应调整回测逻辑。

## 调参记录（2026-08-13）

以 2022-01-04 ~ 2026-08-12、30 只大盘股为样本，从基线迭代到当前版本：

| 版本 | 关键改动 | 总收益 | 最大回撤 | 夏普 |
| --- | --- | --- | --- | --- |
| v1 基线 | 5 日定时调仓卖出 + 固定止盈 25% | +8.96% | −14.4% | 0.22 |
| v2 | 跌破 EMA20 即卖 | +1.70% | −16.7% | 0.09 |
| v3 | EMA20/60 死叉 + ATR 2.5 跟踪 | −16.86% | −27.2% | −0.23 |
| v5 | v3 基础上信号失效卖出 + 放宽入场与择时 | +19.08% | −19.8% | 0.36 |
| v6b | 跟踪止损收紧到 ATR×2 | +26.43% | −17.7% | 0.46 |
| **当前默认** | 2022–2024 训练段网格选优（breadth 0.50/0.25、金叉 10 天、ATR×2.5） | **+15.92%** | **−20.0%** | **0.31** |

**经验教训**：

1. 出场逻辑不是瓶颈——三种趋势出场方案都跑不赢快速轮动，真正拉开差距的是**参与度**（择时放宽后建仓天数从 25% 升到 53%）；
2. 「信号失效才卖」优于「定时卖」：盈利主要来自 signal_loss 退出（胜率 49%、平均 +1.6%）；
3. A 股动量信号衰减快，跟踪止损 ATR×2 优于 ×2.5 / ×3；
4. 买入节奏 5 天显著优于 10 天（信号新鲜度）；
5. **参数是在全样本上试出来的，存在过拟合风险**，下一步必须做样本外（walk-forward）验证后再实盘参考。

## Walk-forward 样本外验证（2026-08-13）

方法：2022-01-01 ~ 2024-12-31 为训练段，用 16 组参数网格（择时阈值 × 金叉窗口 × ATR 倍数）选优；
2025-01-01 之后的样本**完全未参与调参**，用于验证。

```bash
python3 validate.py   # 输出 output/walkforward/comparison.csv 和 best_config.json
```

结果：

| 配置 | 训练段年化 | 训练段夏普 | 测试段年化 | 测试段夏普 | 测试段回撤 |
| --- | --- | --- | --- | --- | --- |
| 训练段最优（当前默认） | 5.97% | 0.51 | 2.05% | 0.20 | −15.4% |
| v6b（全样本调参，参考） | 4.71% | 0.43 | 5.52% | 0.41 | −12.8% |

结论：

1. 策略**样本外仍然有效**（训练段选出的参数在 2025–2026 年取得正收益、夏普 0.20），但收益显著衰减——训练段 5.97% → 测试段 2.05%，符合动量策略的正常衰减规律；
2. v6b 的测试段数字（5.52%、夏普 0.41）**含前视偏差**（参数偷看过 2025–2026），不可作为未来预期；诚实预期应参照训练段最优配置的样本外表现；
3. 稳健性检查：训练段夏普与测试段夏普相关系数 0.70，16 组配置中 69% 在样本外夏普为正，说明选优不是随机碰运气；
4. 因此默认参数已切换为训练段选优配置；想用 v6b 可运行 `python3 main.py --breadth20 0.35 --cross-window 20 --trail-atr 2.0`。

## 策略族对比与结论（2026-08-13）

在 800 只股票、2022-2026 九折滚动样本外框架下，对比了四个策略实现：

| 策略 | 样本外年化均值 | 盈利折占比 | 夏普均值 | 全样本年化 |
| --- | --- | --- | --- | --- |
| 动量（金叉+广度择时） | −0.69% | 30% | −0.58 | 2.56% |
| 动量 + 沪深300 站上 200 日线 | −4.89% | 30% | −0.67 | 4.84% |
| 均值回归（RSI 超跌抄底） | −13.09% | 30% | −0.49 | −9.14% |
| **短期反转因子（5 日最弱 30 只，20 天轮换）** | **+1.21% ~ +1.97%** | **60%** | **0.35~0.39** | **5.54%** |

**结论：短期反转因子是目前唯一在样本外稳定为正的策略族**，且固定默认参数即可
（无需逐折重调）。关键改进是把轮换周期从 5 天拉到 20 天——短期反转的兑现周期
约一个月，5 天轮换不仅砍掉了未走完的反转，还付出了 3.5 倍换手成本。

```bash
# 当前推荐配置
python3 main.py --strategy reversal --rebalance 20 --bottom-n 30
```

已知问题与下一步：

1. 最大回撤仍约 −37%（反转因子买的是最弱股票，市场大跌时 beta 高），下一步加波动率目标仓位；
2. 2026 年 7-8 月大跌段单折年化 −80%，属真实市场行为而非数据问题，需要市场趋势过滤；
3. 未过滤流动性/ST/一字板买不进等真实成交约束，后续补上；
4. 滚动验证脚本：`python3 walkforward_rev.py --rebalance 20`。

### 风控层试验结论（2026-08-13）

试了两层保护，样本外均未通过：

| 保护层 | 全样本 | 滚动样本外（reb=20） |
| --- | --- | --- |
| 无（推荐） | 年化 5.54%，夏普 0.37，回撤 −37% | 年化均值 +1.2%~2.0%，夏普 0.35~0.39 |
| 波动率目标仓位（target 0.15） | 年化 5.29%，夏普 0.39，回撤 −35% | 夏普降至 0.22~0.27，中位数收益下降 |
| 市场大跌过滤（20 日动量 < −5% 清仓） | 年化 2.22%，回撤 −42% | 明显有害（滞后清仓→卖在底部、追高回补） |

结论：**当前推荐配置维持无保护层版本**：

```bash
python3 main.py --strategy reversal --rebalance 20 --bottom-n 30
```

最大回撤 −37% 是该策略的固有特征（持仓为最弱股票、市场大跌时 beta 高）。
要真正降回撤，方向不是"预测大跌"，而是持仓层优化：波动率倒数加权、行业分散、
单票上限等——这些不依赖市场择时信号，样本外塌掉的风险更低。

### 持仓层优化试验结论（2026-08-13）

实现了四项持仓层优化（全部可选，默认关闭）：
波动率倒数加权（`--vol-weight`）、行业分散（`--max-industry`，每行业最多 4 只）、
单票上限（`--max-weight`）、流动性过滤（`--min-amount`，剔除 20 日均成交额
低于 1 亿的股票，另含 ST 与上市不足 60 天剔除，需 `--max-industry` 触发元数据加载）。

| 配置 | 全样本年化 | 全样本夏普 | 滚动样本外年化均值 | 样本外夏普均值 |
| --- | --- | --- | --- | --- |
| 基线（推荐） | 5.54% | 0.37 | +1.2%~2.0% | 0.35~0.39 |
| 四项持仓优化全开 | 7.87% | 0.50 | −4.30% | 0.10 |

**结论：持仓层优化全样本大幅提升，但样本外反而变差，未采用。**

原因：反转因子的收益主要来自"最弱、最波动、流动性偏低"的股票；波动率倒数加权
和流动性过滤恰好把仓位压向"没那么弱"的股票，等于削弱了因子本身的暴露。全样本的
提升来自躲开了个别极端时期，样本外无法复制。**推荐的最终配置仍为基线：**

```bash
python3 main.py --strategy reversal --rebalance 20 --bottom-n 30
```

想实验持仓层优化可加对应开关，但需自行用 `python3 walkforward_rev.py --rebalance 20` 验证样本外。

### 第二轮优化（2026-08-13）：新特征试验结论

在训练段上试了两个新特征并扩大网格到 32 组：

1. **量能过滤（金叉时要求放量）**：有害。带过滤的配置样本外夏普为正的比例仅 31%，不带过滤为 94%，不采用；
2. **波动率调整动量打分**：有害。同一配置改用该打分后，样本外年化从 2.05% 降到 0.33%，不采用；
3. **警惕"测试段最佳"**：扩大网格后，样本外表现最好的几个配置（如 10 天调仓）在训练段年化接近 0 甚至为负——这是测试窗口的运气，不是稳健信号，不应据此换参数（训练/测试夏普相关也从 0.70 降到 0.39）。

**结论：新特征均未通过验证，默认配置维持上一轮训练段选优**（breadth 0.50/0.25、金叉窗口 10 天、ATR×2.5 跟踪止损、原始动量、无量能过滤）。
诚实预期仍为年化约 2%、夏普约 0.2、回撤约 15%。

> 注意：测试窗口已被多轮查看，上述样本外数字存在轻微乐观偏差；如需更严谨的估计，应做滚动多折验证。

### 第三轮：市场情绪特征（2026-08-13）

新增 `src/sentiment.py` 市场情绪数据层（东方财富公开接口，已本地缓存）：

- **板块强度**：26 个主要行业指数日线，计算「20 日动量向上的板块占比」（板块赚钱效应）；
- **龙虎榜净买额**：2022-01 至今全部龙虎榜明细，按日汇总净买额（1116 个交易日）。

策略层新增两个可选情绪过滤（默认关闭）：

| 配置 | 训练段年化 | 训练段夏普 | 测试段年化 | 测试段夏普 |
| --- | --- | --- | --- | --- |
| 无情绪过滤（当前默认） | 5.97% | 0.51 | 2.05% | 0.20 |
| 板块广度 ≥ 0.50 | 2.37% | 0.25 | −2.33% | −0.07 |
| 板块广度 ≥ 0.60 | 3.20% | 0.32 | −1.91% | −0.05 |
| 龙虎榜净买 > 0 | 0.90% | 0.14 | −3.97% | −0.17 |
| 板块 + 龙虎榜 | 0.16% | 0.07 | −6.08% | −0.34 |

**结论：三类情绪过滤在训练段和测试段都让收益变差，均不采用，默认保持关闭。**

原因分析：

1. 板块广度与策略自带的「股票池动量广度」高度重叠，本质是同一个信号换了个样本，加过滤只砍参与度；
2. 这个策略的收益主要来自「在强势时段在场」，情绪过滤切掉的日子恰好包含很多赚钱的日子；
3. 龙虎榜净买额是滞后确认指标——它转正时行情往往已走完一段，作为入场闸门反而错过启动段。

实现与数据已保留（`src/sentiment.py`、`output/sentiment_cache/`），后续若想把情绪信号用作**仓位缩放**或**日报参考**而非入场闸门，可直接复用：

```bash
python3 main.py --require-board-breadth            # 板块情绪过滤
python3 main.py --require-lhb-positive             # 龙虎榜过滤
```
