# 全板块筛选与分析流程（SOP）

> 目标：把发现一个板块的时间，从"热榜刷屏之后"提前到"低位启动 / 资金异动期"，并给所有板块一套可重复的筛选、验证、进出场标准。
> 配套自动化：`stock-daily` 每个交易日 18:00 已自动采集大盘指数、成交额、涨停/跌停/炸板、涨跌家数、行业/概念板块涨跌前五、龙虎榜、热股榜，见 [README](../README.md)。

## 0. 三条基本原则

1. **热榜是滞后的结果，不是信号来源。** 本流程只从三处找板块：量价异动、资金行为、事件日历。
2. **先定大盘环境，再谈板块。** 环境决定仓位上限：强环境敢试错，弱环境只做逻辑最强的方向。
3. **早发现 ≠ 早买入。** 所有发现先入"观察池"，逻辑验证通过才进"持仓池"，全程带着提前写好的退出条件。

## 2. 每日流程（收盘后约 30 分钟）

### Step 1 · 大盘定基调（5 分钟）

看三件事，输出环境三档和仓位上限：

- 指数趋势：上证 / 创业板在 20 日线上方还是下方；
- 量能：两市成交额相对 5 日均量是放大还是萎缩；
- 赚钱效应：涨停家数（约 ≥60 活跃、≤30 冰点）、炸板率（>30% 偏差）、涨跌家数比。

| 环境 | 特征 | 仓位上限 |
| --- | --- | --- |
| 积极 | 指数站上 20 日线 + 放量 + 赚钱效应好 | 高 |
| 中性 | 趋势与量能方向不一 | 中 |
| 防御 | 跌破 20 日线 + 缩量 + 炸板率高 | 低，只做最强逻辑 |

### Step 2 · 板块初筛（10 分钟）

对象是**全部**行业 + 概念板块的涨幅榜，不是只看前五。按优先级找"低位启动型"特征：

1. 位置：距一年高点回撤 >25%，或处于长期底部箱体；
2. 量价：温和放量（量比约 1.2–2.5）、连续小阳，且还没出现连续涨停刷屏；
3. 持续性：连续 3 日以上位于板块涨幅榜前 20，但尚未霸占热榜。

当日涨幅不要求必须为正：允许小幅回调（约 -1.5% 以内），当日收跌时改看 5 日总体涨幅
（≥0.5% 即可继续考察）；只有当日、5 日、20 日同时为负的板块才被排除。

排除三种类型：高位加速型（涨幅巨大 + 天量）、纯消息脉冲（单日暴涨、次日回落）、已连续多日霸榜的拥挤板块。

### Step 3 · 资金验证（5 分钟）

至少满足两条才继续往下走：

- 主力资金：板块主力连续净流入 ≥3 天；
- 融资余额：板块内个股融资净买入持续为正；
- ETF 份额：对应主题 ETF 份额增加、而价格未大涨（机构低位埋伏特征）；
- 龙虎榜：出现机构席位买入（确认不是纯游资一日游）。

### Step 4 · 逻辑体检（10 分钟）

回答四个问题：

1. 催化剂是什么？政策 / 商品价格 / 供需 / 技术突破 / 一次性事件；
2. 催化可持续吗？找"催化链条"，例如：粮价上涨 → 种植收益改善 → 种子、化肥、农药需求；
3. 板块在哪一阶段？低位刚启动（埋伏）→ 趋势中段（顺势）→ 加速末段（接力/派发）；
4. 利好能否落到利润？区分"真受益"与"蹭概念"——同样的涨价，对上游是利好，对纯加工企业可能是成本。

输出逻辑评级：**S**（多重持续强催化）/ **A**（中期催化明确）/ **B**（短期题材）/ **C**（无实质逻辑）。

### Step 5 · 打分入库

五维打分，每项 0–2 分，满分 10：

| 维度 | 2 分 | 1 分 | 0 分 |
| --- | --- | --- | --- |
| 位置 | 低位（距高点回撤 >25%） | 中位 | 高位 |
| 量价 | 温和放量连续走强 | 放量但波动大 | 无量拉升或巨量滞涨 |
| 资金 | 主力净流入 + 机构参与 | 仅散户活跃 | 资金流出 |
| 逻辑 | S/A | B | C |
| 拥挤度(反向) | 无人问津 | 局部讨论 | 霸榜刷屏 |

- 总分 ≥7 且"位置 + 资金"≥3 → 进**观察池**；
- 观察池 + 逻辑评级 A 以上 + 大盘环境允许 → 进**持仓池**（先试错仓）。

### Step 6 · 出计划

每个标的写清：进场条件、仓位、止损线、逻辑破坏条件、预期目标。没有计划的发现不执行。

## 3. 每周流程（周日约 1 小时）

1. 复盘：观察池每个板块的信号是否还在强化，持仓池的逻辑有没有变化；
2. 事件日历：扫下周的政策节点、数据发布时间；
3. 大宗商品周线：确认商品趋势方向是否与板块逻辑一致；
4. 相对强弱：所有板块按近 5/20/60 日涨幅排序，找"排名持续上升、但还没霸榜"的方向；
5. 拥挤度：检查热榜、媒体刷屏程度，对持仓池做止盈预警。

## 4. 每月 / 事件驱动

- 数据日历：FAO 食品价格指数（每月初）、统计局 CPI/PPI（中旬）、PMI、美联储议息、财报季；
- 政策季历：1 月中央一号文件、3 月两会、夏收/秋收收储窗口、五年规划节点；
- 板块地图：每月更新一次"低位 + 催化"的全景图，标记每个板块当前阶段。

## 5. 信号分级速查

| 级别 | 特征 | 动作 |
| --- | --- | --- |
| A | 低位放量启动 | 观察 → 试错仓 |
| B | 趋势中继 | 顺势持有，按趋势线管理 |
| C | 加速末段 | 不追；持有者分批止盈 |
| D | 高位放巨量涨停 | 派发特征，回避 |

## 6. 出场规则（提前写死）

- 逻辑破坏：催化事件被证伪（减产预期落空、政策撤回等）；
- 量价背离：创新高但量能萎缩，或巨量滞涨、长上影；
- 拥挤度见顶：连续霸榜 + 媒体铺天盖地 + 连板股集体加速（情绪高潮）；
- 止损：试错仓 -5% ~ -8%；盈利仓跌破 10 日线，或浮盈回撤 1/3。

## 7. 反面清单（常见陷阱）

- 在热榜上第一次看到时买入 = 接"注意力溢价"；
- "低位"不等于"会涨"，低位埋伏可能要熬很久；
- 把一次性消息当成趋势逻辑；
- 忽略板块内部结构：只有龙头涨是弱结构，普涨才是强结构；
- 只看涨幅不看成交：无量拉升难以持续。

## 9. 与现有自动化的衔接

已自动化：

- `collect.py`（stock-daily）：大盘、情绪、板块涨跌前五、龙虎榜、热股榜；
- `sector_scan.py`（v1，已实现）：全量板块快照预筛、资金流日线（位置/5·20·60 日涨幅/主力连续净流入）、
  四维打分（位置/量价/资金/拥挤度，各 0–2 分，满分 8，总分 ≥4 进候选榜）、
  候选榜 + 入选理由 + 与昨日对比 + 待人工逻辑体检，可选写入 Notion；
- 稳定性：接口失败自动重试（快照分页、历史日线、指数K线），历史数据本地缓存 + 
  GitHub Actions 官方缓存每天恢复/保存，云端日常只需增量更新。

机器分只覆盖可量化维度，SOP 第五维"逻辑"仍由人工完成：
自动化产出候选清单后，人工只做 Step 4 的 S/A/B/C 判断。

尚未自动化、可扩展的方向：

- 融资余额、主题 ETF 份额变动；
- 新闻/涨停原因自动匹配，辅助逻辑体检；
- 融资/龙虎榜机构席位并入资金维度打分。

## 附：默认参数（可按个人风格调整）

| 参数 | 默认值 |
| --- | --- |
| 低位回撤阈值 | 距一年高点 >25% |
| 温和放量量比 | 1.2–2.5 |
| 预筛当日涨幅区间 | -1.5% ~ +6% |
| 当日收跌时的 5 日涨幅门槛 | ≥0.5% |
| 短期趋势校验 | 当日/5日/20日 不全为负 |
| 主力连续净流入 | ≥3 天 |
| 持续上榜天数 | ≥3 天 |
| 机器候选门槛（sector_scan v1） | 四维总分 ≥4（位置/量价/资金/拥挤度 各 0–2，满分 8） |
| 人工观察池门槛 | 五维总分 ≥7 且位置+资金 ≥3 |
| 试错仓止损 | -5% ~ -8% |

> 自动化 v1 的"距一年高点回撤"用收盘价序列计算（资金流日线只带收盘价，不带当日最高价），
> 与真实盘中高点回撤略有差异，属可接受近似。

> 本流程仅为研究框架，不构成投资建议。所有参数与评分规则都应先用历史数据回测验证后再用于实盘。
